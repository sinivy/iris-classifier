# Classificador de Espécies de Flores

Projeto de Machine Learning utilizando Scikit-Learn para classificação de flores do dataset Iris.

## Tecnologias

- Python
- Pandas
- Scikit-Learn
- Matplotlib

## Funcionalidades

- Treinamento de modelo supervisionado
- Avaliação de desempenho
- Geração de previsões
- Visualização de resultados

## Resultado

Acurácia superior a 95%.
